# OneTouch+（ワンタッチプラス）

> **ボタンひとつで、楽しさと笑顔をプラス。**

重度肢体不自由や片麻痺の方でも、**ナースコールボタンを1回押すだけ（ワンキースイッチ・ワンタップ）**で楽しめるエンターテインメント＆意思伝達Webアプリケーションです。

iPad、Fireタブレット、Android、Windows PCなど、ブラウザのあるあらゆる端末で動作します。

---

## 🌟 主な機能

### 1. 2つの選択モード（お父さんのペースに合わせた操作）
* **① 項目スキャンモード**: ボタンが順番に大きく光り、押した瞬間に決定。
* **② 十字線スキャンモード（クロスヘア / XYスキャン）**:
  - 横線（上下移動）を1回目のボタンで固定。
  - 縦線（左右移動）を2回目のボタンで固定。
  - 十字が交差した場所を決定・実行（反応遅延を救済する自動引き戻しアシスト付き）。
* **スキャン速度 5段階**: 超ゆっくり（10秒以上かけて移動する最遅モード）〜 速い まで自由に変更可能。
* **🖐️ サポートOFF（通常タッチモード）**: お母様や介助者が直接指で画面を操作したいときは、ヘッダーのボタン1つで自動選択を完全停止できます。

### 2. 充実のコンテンツ
* 😄 **お笑いシアター**: サンドウィッチマン、中川家、かまいたち、千鳥、粗品、ナイツ、大谷翔平、志村けん・ドリフなど、お父さんが大好きな動画をワンボタンで次々と鑑賞・スキップ。
* 🎆 **ワンボタン花火**: ボタンを押すたびに夜空に大輪の花火が打ち上がり、爽快な音と光が広がるリラクゼーション。
* 🎰 **ラッキースロット**: タイミングよくボタンを押して絵柄を揃える達成感ゲーム。
* 🗣️ **おはなしカード**: 「お茶」「ありがとう」「テレビ」「痛い（頭・お腹・手・足・おしっこ下腹部など部位選択可）」を温かみのある高音質AI肉声で発話。

## 🚀 無料・スリープなし（待ち時間0秒）でWeb公開する方法

Renderのような休眠（スリープ）がなく、24時間365日いつでもアクセスした瞬間に0.5秒で開く**GitHub Pages**での公開がおすすめです。

1. GitHubに新しいリポジトリ（例: `onetouch-plus`）を作成します。
2. このフォルダ内のファイル一式をアップロード（push）します。
3. リポジトリの `Settings` → `Pages` を開き、Branchを `main`（または `master`）にして保存します。
4. 数分で `https://ユーザー名.github.io/onetouch-plus/` という公開URLが発行され、世界中からいつでも瞬時にアクセスできるようになります！

## 💻 手元ですぐに動かす場合
* **パソコン**: `index.html` をダブルクリックしてブラウザで開く。
* **Fireタブレット等**: `start_server.bat` を起動し、表示されたIPアドレス（例: `http://192.168.0.5:8080`）をタブレットのブラウザに入力。
